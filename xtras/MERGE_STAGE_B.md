# Xtras merge: Stage A/B findings (read-only analysis)

Source of truth: `merge_manifest.json` (generated by `diff_xtras.py`). Nothing in either pack has been changed.

## Size of the real gap
- Revised files by classification: 1,493 identical to Main at the same path, 1,231 identical to a Main file at another path,
  76 same path / different content, 52 same logical name / different content, **283 unique (2.0 MB)**.
- Main-only content: 927 files, 243 MB.

## Things that are already in Main (nothing to merge)
- The eight individual Master Levels maps in Revised (`canyon`, `hack2`, `kickatk`, `mee2`, `newcat3`, `process`, `system`,
  `tuff`) are byte-identical to Main's `ML_MAP44`-`ML_MAP51` (SHA-256 match).
- Revised `e2m5b.wad` is byte-identical to Main's `psx01b.wad`.
- Revised `psx08.wad` is byte-identical to Main's `psx07.wad`.

## ZScript (after counting `extend class` blocks)
- 32 shared class names. Revised has **no method of its own that Main lacks** except `DCX_EventHandler.TextureFixes`.
  Main has extra methods Revised lacks (`BasePSXMapTextures`, `BlankMapTransitions`, `CabalLevelOrder`,
  `WadFusionAlternateHUD`, `DrawString`, `DrawTexture`, `A_CyberdemonAttack`, ...). Main's code is a superset of the old code.
- Revised-only classes and where they are used (all four live in Revised scripts):
  `DCX_LesserMastermind` (Actors.zsc, EventHandlers.zsc, mapinfo.txt), `DCX_PlaystationSecrets`,
  `DCX_Multiplayerweaponremoveal`, `DCX_TotalCarnageMonsterPlacementsBackup` (Levelpostprocessors.zsc only).
- 18 of the 32 shared bodies differ; most differences are Main-side additions, still to be read member by member.

## CVars
- Real new Revised feature: `dcx_TextureFixes` (bool, default true): declared, in the menu, and read by two scripts.
  It applies the 21 files under `patches/fixes/` plus `rw32_b` and the `sw1skull`/`sw2skull` switch patches.
- **Declared but never read by any Revised script or font/bar definition**: `D64_Hud_toggle`, `Plu_Hud_toggle`,
  `Tnt_Hud_toggle` (menu entries only), `always_pistol_start`, `keep_inventory_items` (CVARINFO only).
- Shared cvars with different settings: `dcx_CustomMonsters` default (Main true, Revised false), `dcx_playstationmaps`
  (Main int, Revised bool), and `hud_toggle`, `fs_toggle`, `ssgtoggle`, `Health_Cross_Toggle`, `dcx_3DO_Music`
  (Main `user`, Revised `server`). Main wins on all of them.

## Unique art and audio that nothing references
- The HUD number fonts and status bars (Plutonia, Plutonia Revisited, TNT, TNT Revilution, Freedoom, Jaguar, 89 + 10
  files) are defined in Revised's FONTDEFS (eight new font names) but no script, menu or SBARINFO uses those fonts or the
  `tnbar`/`plbar`/`prbar`/`trbar` images. They are unfinished in the Revised beta itself.
- The nine unique Doom 64 alternate tracks, `in_ep42.txt`, `misctextures.wad` and `d2spfx20.wad` are also never referenced.
- Used by Revised code: sprites `LCYB`, `LSPI`, `BSP2`, `MOTH` (Actors.zsc) with sounds `DSLCY*`/`DSWID*` (SNDINFO);
  `thyfleshconsumed_levels_X.txt` (included from Revised's `mapinfo.txt`).

## Alternate PSX / Thy Flesh Consumed
- Revised's PSX01-07, PSX01B, PSX02B and TITLEMAP are different map versions; none has an identical copy in Main
  (11 same-path conflicts). Main also has PSX03B and PSX09 that Revised lacks.
- Revised's Episode 4 intermission art uses other paths for the same names Main defines (`wimap3`, `wia301xx`, ...), so
  both cannot be loaded together unchanged.

## What this means for the merge
- Real new behaviour to port: Texture Fixes, `DCX_LesserMastermind` and the extra monsters with their sounds, the three
  Levelpostprocessors classes, the Thy Flesh Consumed level file, and the alternate PSX map set (needs renamed lumps).
- Not behaviour but unreferenced assets: HUD fonts/bars, the TNT/Plutonia/Doom 64 HUD toggles, the alternate tracks,
  `always_pistol_start`, `keep_inventory_items`. Keeping them means either storing them inactive or writing new code
  to use them. That is a decision for the owner, not a port.
